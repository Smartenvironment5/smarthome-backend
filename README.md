# Smarthome backend API

## Tech stack
- Minimal API
- .NET versie 10.0.400

## Getting started

### 1. Clone de repository
```bash
git clone https://github.com/Smartenvironment5/smarthome-backend
cd smarthome-backend
```

### 2. Installeer just (optioneel)
```bash
winget install Casey.Just
```
Hiermee kan je dotnet scripts runnen gedefineerd in de `justfile` file

### 3. Start de API
```bash
just run
```

- Open de swagger UI -> `http://localhost:5100/swagger/index.html`
